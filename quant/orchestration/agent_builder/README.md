# Agent Builder configuration

Place Agent Builder app exports here:

- Agent definitions and system prompts (one file per agent or YAML)
- MCP server registrations (Elastic, MongoDB)
- Tool bindings mapping to `quant/agents/*.py` handlers

This directory is documentation-first until GCP project credentials are available.

See the [Architecture wiki](https://github.com/atshalahmedkhan/Team_UB/wiki/Architecture).
